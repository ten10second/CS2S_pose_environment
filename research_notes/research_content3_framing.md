# 研究内容三：前馈流式约束下的时序累积增强感知

## 一句话定位

研究内容三不是再做一个新的重建模块，也不是单纯加一个时序网络，而是回答：

**当研究内容一已经给出世界系 4DGS 表征，研究内容二已经把它沉淀成地理地址化记忆后，能否不依赖复杂递归网络、跨帧注意力或查询传播，仅通过世界系持久状态的前馈更新，让当前帧感知获得稳定、可解释、低延迟的时序增益？**

换句话说，研究内容三是整篇课题的“感知兑现层”：前两项负责把世界状态建出来、存下来，第三项负责证明这些世界状态确实能提升在线感知。

## 现在说不清楚的原因

当前文本中有几个正确但分散的关键词：

- 世界系持久状态；
- 可微渲染；
- 单帧监督；
- 不确定性驱动更新；
- 动态实例累积；
- 语义占用、检测、可行驶空间；
- 误差有界与稳定性。

这些点都对，但如果没有中心句，会听起来像“把很多模块串起来”。建议把它们压到一个主轴下面：

**用世界系持久状态承担时序信息，用不确定性前馈更新替代重型时序融合，用感知任务验证这种累积是否真的带来收益。**

## 推荐题目

可以把研究内容三改写成：

**基于世界系持久状态的弱时序流式感知增强方法**

或更技术一点：

**前馈因果约束下的世界系状态累积与感知增强**

如果保留原题，“前馈流式约束下的时序累积增强感知”也可以，但解释时要把“时序累积”明确解释为“世界系状态累积”，否则容易被理解成普通 temporal fusion。

## 输入输出定义

在时间步 `t`：

- 输入：当前观测 `O_t`，当前位姿 `p_t`，上一时刻世界系持久状态 `S_{t-1}`，以及地理地址化记忆中读出的局部状态 `M_{t-1}`。
- 输出：更新后的世界系状态 `S_t`，以及当前帧感知结果 `Y_t`，例如语义占用、检测框、可行驶区域、运动/占用流和逐项置信度。

核心更新可以概括为：

```text
E_t = Encode(O_t, p_t)
S_t = Update(S_{t-1}, E_t; uncertainty, visibility, geo-consistency)
Y_t = DecodeOrSplat(S_t)
```

或者更像论文里的形式：

```text
S_t = U(S_{t-1}, E_t, p_t, sigma_t)
Y_t = D(Pi(S_t))
```

其中 `S_t` 是世界系状态，`E_t` 是当前帧证据，`sigma_t` 是不确定性，`Pi` 是投影/泼溅到 BEV 或 voxel 的算子，`D` 是轻量感知头。

## 三个技术模块

### 1. 世界系状态读出与当前证据构造

从 Geo GaussianMemory 中按当前位姿和地理范围读出局部持久状态，包括静态背景高斯和动态实例高斯。

同时，用当前相机、LiDAR、GPS/IMU 构造当前帧证据，例如短窗口 4DGS、稀疏占用、BEV 特征或高斯 token。

这一部分回答：“当前帧看到了什么？历史世界状态里已经有什么？”

### 2. 不确定性驱动的前馈状态更新

不做历史特征队列，不做跨帧注意力，不做长期 query 传播，而是对每个空间单元或高斯原子做一次前馈更新。

高置信历史区域保持稳定；低置信、新观测或冲突区域更积极吸收当前证据；遮挡或不可见区域只做衰减，不盲目覆盖。

这一部分回答：“哪些历史应该保留？哪些应该被当前帧修正？哪些应该遗忘？”

### 3. 累积状态到感知输出的轻量解码

将更新后的世界系状态投影或泼溅到 BEV/voxel，再用轻量头输出占用、语义、检测、可行驶区域和置信度。

核心不是设计一个更大的 decoder，而是验证：当状态本身已经累积了几何和语义，感知头可以更轻、更稳定。

这一部分回答：“这种世界状态累积是否真的带来当前帧感知增益？”

## 科学问题

研究内容三的科学问题可以写成：

**在自动驾驶流式感知中，时序增益是否可以主要来自统一世界系下的几何与语义状态累积，而不是复杂显式时序网络本身？**

可以拆成三个子问题：

1. 在前馈因果约束下，如何用当前观测稳定更新世界系持久状态？
2. 不确定性、可见性和几何一致性如何决定状态的保留、修正和遗忘？
3. 相比重型时序模块，世界系状态累积能否以更低复杂度获得可比的占用/检测增益？

## 贡献表述

建议不要把贡献说成“提出一个流式感知模型”，这样太泛。可以说成三点：

1. **提出一种弱时序流式感知范式**：用世界系持久状态承载历史信息，而不是维护长历史特征队列。
2. **设计不确定性驱动的前馈状态更新机制**：在单步因果更新中完成保留、修正和遗忘。
3. **建立时序增益归因实验协议**：通过打乱位姿、移除记忆、移除不确定性、替换为显式时序模块等实验，分析性能提升究竟来自世界系累积还是网络时序建模。

## 不要过度声称

这部分最危险的说法是：

**“我们完全不需要时序模块，还能超过所有 SOTA。”**

这个容易被质疑，也不一定必要。

更稳的说法是：

**本研究不追求证明显式时序模块无用，而是研究在世界系持久状态足够明确的条件下，是否可以用更简单、更可解释、更低延迟的前馈累积机制获得主要的流式增益，并分析这种增益的来源。**

## 实验设计

### 必做 baseline

- 单帧模型：只用当前帧，不用记忆。
- 短窗口 4DGS：只用研究内容一输出，不写长期状态。
- 记忆读出但不更新：验证持久状态本身的贡献。
- 简单 EMA / feature queue：排除“随便累积一下也行”的质疑。
- 显式时序模块：例如 BEV queue、query propagation 或 recurrent fusion。

### 必做 ablation

- 去掉世界系对齐；
- 去掉不确定性更新；
- 去掉动态实例分支；
- 打乱历史记忆的位姿；
- 使用错误/扰动 GPS；
- 只保留静态记忆或只保留动态记忆；
- 不同累积帧数和不同记忆容量。

### 关键指标

- Occupancy：mIoU、RayIoU、near/far region mIoU；
- Detection：mAP、NDS；
- Temporal consistency：跨帧预测抖动、重访一致性；
- Confidence calibration：ECE 或按置信度分桶的误差；
- Efficiency：延迟、显存、参数量、memory size。

## 推荐开题答辩说法

如果老师问“研究内容三到底干什么”，可以这样说：

**研究内容三关注的是：前两项得到的世界系高斯表征和地理地址化记忆，如何真正转化为在线感知增益。传统流式感知往往靠跨帧注意力、递归网络或 query 传播来获得时序收益，但这些模块复杂、延迟高，也很难解释增益来源。我的思路是把历史信息沉淀到统一世界坐标系下的持久状态中，每一帧只用当前观测对这个状态做一次不确定性驱动的前馈更新，再把更新后的状态投影到 BEV 或 voxel 输出占用、检测和置信度。这样研究内容三要验证的不是“再设计一个更强时序网络”，而是“世界系状态累积本身能否成为更简单、更可解释的流式感知增益来源”。**

## 最终定位

研究内容一解决“世界状态怎么前馈生成”。

研究内容二解决“世界状态怎么长期维护”。

研究内容三解决“世界状态怎么反过来增强当前感知”。

三者关系可以概括为：

```text
R1: 建状态
R2: 存状态
R3: 用状态提升感知，并解释时序增益来自哪里
```
