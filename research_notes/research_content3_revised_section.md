# 研究内容三：地理高斯记忆辅助的流式感知

## 3. 研究内容三：地理高斯记忆辅助的流式感知

现有流式三维感知方法通常通过历史 BEV 特征、递归 hidden state、跨帧注意力或 object query 传播来利用历史信息。例如 BEVFormer 通过 temporal self-attention 融合历史 BEV 表征，StreamPETR 将历史信息以 object query 的形式逐帧传播，SparseBEV 通过时空采样在多帧视频中聚合检测证据。这类方法已经证明历史信息对 3D 检测、占用预测和动态场景理解有显著帮助，但它们通常把历史信息保存在网络特征或 query 中，缺少明确的世界坐标语义，也难以长期维护和重访复用。

本研究内容不试图否定上述时序方法，而是从另一个角度提出问题：**如果研究内容一已经能生成世界系 4DGS，研究内容二已经把这些高斯状态维护成地理地址化记忆，那么当前帧感知时能否直接利用这份地理高斯记忆，而不是完全依赖历史特征队列或复杂时序网络？**

因此，研究内容三的定位可以概括为：

```text
研究内容一：生成当前短窗口的世界系 4DGS
研究内容二：把世界系 4DGS 写入地理高斯记忆
研究内容三：当前感知时读取附近地理高斯记忆，并与当前观测融合，提升在线占用、检测和可行驶区域预测
```

也就是说，研究内容三关注的不是“如何再设计一个更强的 temporal attention”，而是研究**地理高斯记忆如何服务当前帧感知**。它的核心科学问题是：

**在当前传感器观测不完整、不稳定或存在遮挡时，地理高斯记忆中维护的静态环境状态、短期动态实例和置信度信息，能否为当前帧占用、检测和可行驶区域预测提供可解释的增益？**

这一定义比“时序累积增强感知”更清楚：本研究内容使用历史信息，但历史信息不是按时间保存为多帧特征，而是按地理位置保存为可查询的高斯记忆。当前帧处理时，系统只读取当前位置附近与任务相关的局部记忆，并与当前观测进行可信度仲裁。

## 3.1 地理高斯记忆中保存什么

地理高斯记忆不是简单保存“过去这个地方出现过什么”，更不是把所有历史车辆占用直接叠加成当前占用。它需要区分三类信息：

```text
M = {M^sta, M^dyn, M^prior, U}
```

其中，`M^sta` 是静态环境记忆，`M^dyn` 是短期活跃动态实例，`M^prior` 是长期动态统计先验，`U` 是置信度和不确定性信息。

### 3.1.1 静态环境记忆

静态环境记忆用于保存道路、路沿、建筑、车道线、交通标志、可行驶区域边界等长期稳定结构。这部分信息可以长期维护，因为它们在世界坐标系中具有稳定地理位置。

例如，对于某个 ENU 坐标或地理 tile，系统可以维护：

```text
道路/路沿/建筑等静态语义
静态高斯参数或稀疏占用状态
高度、几何形状和可见性
最近观测时间
多次观测一致性
置信度和不确定性
```

这类信息可以帮助当前帧处理遮挡、远距离稀疏观测和单帧不稳定问题。例如当前图像中某个路沿被车辆挡住，但历史静态记忆中已经多次确认该处是路沿，那么当前帧的可行驶区域和占用预测可以参考这部分记忆。

### 3.1.2 短期活跃动态实例

动态车辆和行人不能被写成静态地图。过去某个位置有车经过，并不表示现在仍然有车。因此，动态目标只以短期实例状态维护：

```text
o_j = (G_j, x_j, v_j, heading_j, lifecycle_j, confidence_j, last_seen_j)
```

其中，`G_j` 表示该实例对应的局部高斯或几何表示，`x_j` 表示世界系位置，`v_j` 表示速度，`lifecycle_j` 表示生命周期状态，`last_seen_j` 表示最近一次被观测到的时间。

短期动态实例的作用不是替代当前传感器，而是在当前观测不完整时提供短时连续性。例如：

```text
active: 当前帧观测支持该实例
missing: 短时遮挡或漏检，但根据速度和最近观测仍可能存在
retired: 长时间未观测到，不再参与当前占用
```

只有 `active` 和短时 `missing` 的实例参与当前动态占用估计。已经 `retired` 的历史车辆不会被当成当前车辆。

### 3.1.3 长期动态统计先验

如果某个路口过去有很多车辆经过，这部分历史不能说明“现在有车”，但可以形成动态先验：

```text
该区域车流频繁
动态遮挡概率高
当前观测模糊时车辆出现先验较高
该区域值得保留更高分辨率记忆
静态更新时需要避免把车辆误写入静态地图
```

因此，历史动态统计只影响风险、置信度、记忆保留优先级和新生动态实例的先验，不直接作为当前占用输出。

当前占用应被分解为：

```text
Occ_t(x) = Occ_t^sta(x) + Occ_t^active_dyn(x)
```

而不是：

```text
Occ_t(x) = 历史所有车辆占用的并集
```

这一区分是研究内容三成立的关键。

## 3.2 当前帧如何读取记忆

在每个时间步 `t`，系统首先根据当前车辆位姿 `p_t` 和任务范围 `r`，从研究内容二构建的 Geo GaussianMemory 中读取局部地理高斯记忆：

```text
M_t^local = Read(M_{t-1}, p_t, r)
```

该局部记忆包括：

```text
当前位置附近的静态高斯瓦片
短期活跃动态实例
历史动态统计先验
各状态元素的置信度、不确定性、最近观测时间和可见性
```

同时，系统利用当前帧传感器构造当前观测证据：

```text
E_t = Encode(O_t, p_t)
```

其中，`O_t` 表示当前相机、LiDAR 和 GPS/IMU 位姿观测，`E_t` 可以包括当前帧高斯 token、BEV/voxel 特征、深度投影、语义投影、检测候选和动态实例候选。

这一模块的本质是回答三个问题：

```text
当前帧看到了什么？
这个地理区域过去维护了什么？
当前观测和历史记忆在世界坐标系中如何对应？
```

与普通时序方法不同，本研究不是沿时间维度读取 `t-3, t-2, t-1` 的历史特征，而是沿空间维度读取当前位置附近的地理记忆。也就是说，历史信息仍然被使用，但它已经被压缩并沉淀为世界坐标系下的局部环境状态。

## 3.3 当前观测与地理记忆的可信融合

读取局部记忆后，系统需要判断当前观测和历史记忆谁更可信。这是研究内容三的核心模块。

对于静态区域，融合规则可以概括为：

```text
当前观测强且与记忆一致：提升置信度
当前观测强但与记忆冲突：标记变化或降低历史置信度
当前观测弱或被遮挡：保留高置信历史记忆
历史置信度低：更容易被当前观测修正
长期未观测区域：置信度衰减
```

形式上，可以用自适应权重进行更新：

```text
S_t^i = (1 - alpha_t^i) S_{t-1}^i + alpha_t^i \hat{S}_t^i
```

其中，`\hat{S}_t^i` 是当前观测给出的估计，`alpha_t^i` 由当前观测质量、历史置信度、可见性、位姿协方差和最近观测时间共同决定：

```text
alpha_t^i = f(conf_obs, conf_hist, visibility, pose_cov, age)
```

对于动态目标，当前观测仍然是主要依据。短期活跃实例只在遮挡、漏检、传感器异步或观测噪声较大时提供运动连续性：

```text
Dyn_t = Fuse(CurrentDet_t, Predict(ActiveTracks_{t-1}))
```

如果当前观测置信度高，则当前观测主导；如果当前观测缺失但上一时刻实例刚刚出现且速度连续，则保留一个置信度衰减的短期预测；如果长期未观测，则实例退休。

这样，地理记忆不是替代当前传感器，而是作为当前感知的外部状态和可信度参照。

## 3.4 输出当前帧感知结果

经过记忆读取与可信融合后，系统得到当前时刻的增强状态：

```text
\bar{S}_t = Fuse(M_t^local, E_t)
```

随后将该状态投影或泼溅到 BEV/voxel 空间，并通过轻量感知头输出当前帧结果：

```text
Z_t = ProjectOrSplat(\bar{S}_t)
Y_t = Head(Z_t)
```

其中，`Y_t` 可以包括：

```text
语义占用
3D 检测框
可行驶区域
动态占用流
逐区域置信度
```

研究内容三的重点不是设计一个更大的感知头，而是验证：当当前帧感知能够访问地理高斯记忆时，是否能在遮挡、远距离稀疏观测、重复经过同一区域、动态目标短时漏检等场景中获得更稳定、更完整的输出。

## 3.5 与普通流式时序方法的区别

普通流式时序感知通常是：

```text
历史 BEV/query/feature -> temporal network -> 当前感知
```

研究内容三则是：

```text
地理高斯记忆 + 当前观测 -> 可信融合 -> 当前感知
```

两者都使用历史信息，但历史信息的组织方式不同：

```text
普通时序方法：按时间保存历史特征
本研究方法：按地理位置保存世界状态
```

因此，本研究并不声称完全替代显式时序模块，而是探索：显式时序模块中负责历史对齐、静态环境累积、短期遮挡恢复和输出平滑的一部分功能，能否由地理高斯记忆和前馈可信融合机制承担。

## 3.6 相关研究支撑

这一研究方向可以由五类相关工作支撑。

第一类是基于显式时序融合的流式感知方法，如 BEVFormer、StreamPETR 和 SparseBEV。它们证明历史 BEV 特征、object query 和多帧时空采样能够显著提升 3D 检测和占用预测，但历史信息通常存在隐式特征空间中。

第二类是 occupancy world model 和流式占用预测方法，如 OccWorld、GaussianWorld 和 Drive-OccWorld。它们说明自动驾驶感知可以被理解为世界状态演化问题，而不只是单帧识别问题。

第三类是高斯或稀疏状态表示方法，如 GaussianFormer、S2GO、ReconDrive 和 StreamSplat。它们表明语义高斯、动态高斯和稀疏状态可以作为三维占用、重建和动态场景理解的紧凑表示。

第四类是地图记忆与长期更新方法，如 Neural Map Prior 和 LT-Gaussian。它们说明静态环境可以跨时间维护为可更新的地图或高斯状态。

第五类是动态占用与占用流方法，如 Occupancy Flow Fields。它们说明动态物体不能简单写入静态地图，而需要以速度、轨迹或 flow 的形式建模。

这些工作分别证明了历史信息有用、世界状态建模有用、高斯状态可表达三维场景、静态地图可长期维护、动态目标需要实例或 flow 表达。本研究内容则尝试把这些能力统一到“地理高斯记忆辅助的流式感知”中。

## 3.7 实验验证思路

为了证明地理高斯记忆确实服务于当前感知，而不是只是增加了一个复杂模块，本研究需要设置清晰的对照实验。

基础对比包括：

```text
单帧感知模型
普通 BEV/query 时序模型
只使用当前 GeoSensor4DGS 的模型
使用地理高斯记忆辅助的模型
```

关键消融包括：

```text
去掉静态高斯记忆
去掉短期动态实例
去掉历史动态统计先验
去掉不确定性仲裁
打乱地理记忆位置
扰动 GPS/IMU 或外参
改变记忆半径和记忆容量
```

如果使用地理高斯记忆后，当前帧占用、检测和可行驶区域在遮挡、远距离、重复经过区域和短时漏检场景中更稳定；同时打乱地理位置或去掉置信度仲裁后性能下降，则可以说明该方法确实利用了世界系记忆，而不是单纯依赖更大的网络容量。

## 3.8 小结

研究内容三可以最终概括为：

**地理高斯记忆辅助的流式感知。**

它研究的是：当前帧感知时，如何读取当前位置附近的地理高斯记忆，如何判断记忆与当前传感器观测谁更可信，以及这种记忆辅助是否能够提升当前帧占用、检测和可行驶区域预测的稳定性、完整性和可解释性。

与原来的“前馈流式约束下的时序累积增强感知”相比，这一表述更直接地说明了研究对象和方法边界：本研究不是保存所有历史车辆，也不是完全替代时序模型，而是把历史信息以地理高斯记忆的形式组织起来，在当前帧感知中作为可查询、可更新、带置信度的外部状态使用。
