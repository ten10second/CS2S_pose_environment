# GT 前帧条件下的下一帧训练

## 本次目标

给清楚的前帧 RGB 参考，利用前后帧 LiDAR、相对位姿和当前 satellite 条件生成后一帧。
车辆与建筑应延续参考外观，同时遵循新的位置、视角和遮挡。

## 已核对的现状

- 原训练已经使用前帧 GT latent，每个去噪时间步都能读取；当前帧 GT 是标准扩散目标。
- 原训练默认 10% history dropout，混入了无前帧条件的样本。
- 最近的可视化从生成首帧开始递归，混合了前帧参考质量和递归误差。
- 降低全图 epsilon MSE 不等于学会车辆身份保持；GT 像素指标也不能替代参考外观检查。

## 有界修改

1. 默认训练任务设为 `gt_next_frame`，强制正确前帧 GT、history dropout=0；无历史消融必须显式选择另外的任务。
2. 用一个训练数据准备入口明确区分 previous GT 条件和 current GT 目标，并在日志/检查点保存任务来源。
3. 增加独立 GT 帧对生成验证；每对都重新读取前帧 GT，不递归传入其他预测；保存前帧参考、预测后帧、真实后帧三联图。
4. 固定帧对和采样噪声用于比较训练进度，RGB/edge 误差仅标记为保真度诊断，不自动判定身份保持成功。
5. 保留已有权重可用于仅加载参数后重新开始该任务；严格续训不得默默改变任务、数据顺序或 dropout。

## 验证标准

- 训练条件始终来自前帧，当前帧仅作为目标；无误用当前 GT 作为历史。
- 所有 GT-pair 训练样本都启用历史；不允许 OFF/dropout 与该任务同时使用。
- 帧对生成验证没有 GT 当前帧输入采样器，也没有跨帧对预测反馈。
- DDP 验证临时解包后恢复，验证前后优化器/可训练状态不被修改。
- 小型单元测试与 GPU4/5 上有界真实数据训练/采样通过；不据此声称车辆身份已保持。

本次为已确认任务的实现收敛；不是新的身份损失或几何机制，也不把移除 dropout 当成身份保持的证明。
